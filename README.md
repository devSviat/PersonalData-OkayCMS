# Згода на обробку персональних даних для OkayCMS

Модуль працює лише на форку OkayCMS: https://github.com/devSviat/OkayCMS-Fork. На стоку 4.5.3 він не підтримується.

Модуль додає до форм магазину чекбокс «Я даю дозвіл на обробку особистих даних». Поки
покупець його не позначить, форма не відправляється і показує помилку.

## Які форми

В адмінці модуля для кожної форми є окремий перемикач:

- кошик;
- реєстрація;
- зворотний зв'язок;
- замовлення дзвінка;
- коментарі до товару;
- коментарі.

Чекбокс у шаблони теми вставляють модифікації з `Init/module.json`, редагувати файли теми
не треба. Для іншої форми додайте в шаблон теми шорткод `{confirm_personal_data_processing}`
там, де має стояти чекбокс.

## Вимоги

- [Форк OkayCMS](https://github.com/devSviat/OkayCMS-Fork);
- PHP 8.5.

## Встановлення

1. Завантажте архів з [останнього релізу](https://github.com/devSviat/PersonalData-OkayCMS/releases/latest)
   і розпакуйте його в `Okay/Modules/`. Має з'явитися каталог `Okay/Modules/Sviat/PersonalData`.
2. «Модулі» → «Мої модулі»: встановіть і увімкніть PersonalData.
3. Відкрийте сторінку модуля й позначте форми, де потрібна згода.
4. Очистіть `compiled/`, щоб тема зібралась уже з модифікаціями.

## Тести

Тести лежать у `tests/` і в архів релізу не потрапляють. Щоб їх запустити, покладіть модуль
і тести у форк:

```
{OkayCMS_root}/
├── Okay/Modules/Sviat/PersonalData/
└── tests/Modules/Sviat/PersonalData/
```

```bash
cd {OkayCMS_root}
vendor/bin/phpunit tests/Modules/Sviat/PersonalData
```

CI на кожен PR перевіряє синтаксис під PHP 8.5 і запускає ці тести у форку. Після мерджу в
`main`, якщо версії з `Init/module.json` ще немає серед тегів, CI ставить тег і публікує
реліз з архівом.
